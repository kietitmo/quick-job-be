# Quick Job Search Website - Backend Development  

## **Overview**  
This project involves developing a scalable backend for a job search platform that enables user authentication, job postings, and application management. The system includes advanced features such as email verification, password recovery, and role-based access control, ensuring secure and efficient interactions for users.  

---

## **Features**  
1. **User Authentication**  
   - Register and login using secure JWT-based authentication.  
   - Email verification during registration.  
   - Password recovery via email.  

2. **Role-Based Access Control**  
   - Admins: Manage job postings and oversee platform activity.  
   - Employers: Post and manage job listings.  
   - Job Seekers: Search, filter, and apply for jobs.  

3. **Job Postings and Application Management**  
   - Employers can create, update, and delete job postings.  
   - Job seekers can apply to job postings and manage their applications.  

4. **Search and Filter Jobs**  
   - Optimized search functionality with filters for categories like job type, location, and salary range.  

5. **Scalability and Efficiency**  
   - APIs built with NestJS for modularity and scalability.  
   - Data persistence and management using TypeORM with PostgreSQL.  
   - Containerized deployment using Docker.  

---

## **Technologies Used**  
- **NestJS**: A progressive Node.js framework for building efficient and scalable server-side applications.  
- **TypeORM**: An Object Relational Mapper (ORM) for seamless database interactions with PostgreSQL.  
- **PostgreSQL**: A powerful, open-source relational database.  
- **JWT**: JSON Web Tokens for secure authentication and authorization.  
- **Docker**: For containerization and consistent deployment.
